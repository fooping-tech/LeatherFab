# 縫い穴生成エンジン（`src/leather/stitch.js`）

UI から独立した純粋関数。入力は折れ線（外形を 0.02 mm で平坦化し、縁から `offset` だけ内側に入れた線）と `StitchPattern`、出力は穴の位置・向き・区間ごとの実ピッチ・警告。同じ入力は常に同じ出力（決定論）。

## 弧長と弦長

- `spacing: "arc"` — 曲線に沿った距離でピッチを測る。
- `spacing: "chord"` — 隣り合う穴中心の直線距離でピッチを測る（目打ちの刃が実際にまたぐ距離）。曲線上では弧長ピッチより穴が密になる。既定値。
- 弧長は平坦化折れ線の累積長（`polyline.js`: `curve`, `pointAt`, 二分探索）。弦長は「この穴から直線距離 c になる曲線上の次の点」を区間分割＋二分法で求める（`marchChord`）。区間を n 分割する弦長 c は、n 歩で終点に着くよう二分法で解く（`chordPositions`）。曲線が 1 弦の中で折り返す場合は弧長配置にフォールバック。

## 配置モード（`fit`）

| fit | 動作 |
|---|---|
| `fit`（自動フィット） | 区間長 L、目標ピッチ p に対し n = round(L/p)（最低 1）、実ピッチ L/n。偏差 \|L/n − p\|/p が `maxDeviation`（既定 12%）を超えると警告 |
| `fixed`（ピッチ固定） | 始点から p 刻み。余りは区間末尾に残す。最後の間隔が 0.75p 未満なら警告 |
| `count`（穴数優先） | 指定穴数 N。アンカー穴（角・端）を除いた残りを区間長に比例配分（最大剰余法、各区間 1 以上） |

## 角（`corner`）

角は折れ線の頂点で転回角 ≥ `cornerAngle`（既定 40°）のもの。0.02 mm 平坦化では半径 0.5 mm 以上の円弧は 1 頂点あたり 33° 未満しか曲がらないため、フィレットは角とみなされない。

| corner | 動作 |
|---|---|
| `apex` | 角の頂点に穴を置く。角で区間を分け、各区間を独立に配分（角穴は共有） |
| `straddle` | 頂点には置かず、頂点の前後 ±p/2 に対称に 1 対置く（ステッチが角を斜めに渡る） |
| `auto` | 角ごとに選択。転回 80° 以上（直角以下）または余裕が 1.2p 未満なら必ず apex。それ以外は隣接 2 区間の偏差和が小さい方 |
| `none` | 角を無視して 1 区間として配置 |

## 閉曲線・端・方向

- 閉曲線で角が無い場合: 1 区間、n = round(L/p) 穴、`startOffset` の位置から開始（終点は始点と同じなので重複しない）。
- 開いた線: 両端に穴（`startMargin` / `endMargin` だけ内側）。
- `reverse`: 進行方向を反転。接線が 180° 回り、斜めの穴（菱目・フレンチ・スリット）の傾きが鏡像になる（逆目打ち）。
- `flip`: 傾きだけ反転（裏から加工するミラー用）。
- 重複防止: 隣接穴の距離が max(width, min(p/2, length)) 未満なら 1 つ省いて警告（隣接する角の straddle 対など）。

## 穴の向き

接線は ±0.25 mm の中心差分で求める（平坦化の面ごとのブレを抑える）。穴の向き = 接線角 + sign × `angle`（sign = reverse × flip）。

## 穴形状（`holeContour`）

| shape | 形 | 既定（幅 × 長さ, 角度） |
|---|---|---|
| round | 円（頂点数は 4 の倍数、弦のサグ ≤ 0.005 mm） | Ø1.0 |
| diamond | 菱形（長軸 length、短軸 width） | 0.6 × 2.0, 30° |
| french | 両端が半円のスロット | 0.5 × 2.4, 15° |
| slit | 細い長方形 | 0.3 × 2.0, 45° |
| flat | 線に沿った長方形 | 0.5 × 2.0, 0° |

## 辺の範囲（部分的な縫い線）

辺の範囲（ノード a → b）は、外形全体を内側にオフセットしたリングのうち、両端ノードを「その端の辺の法線方向に offset だけ押し込んだ点」に最も近い位置で切り出す。凸の角では内側リングの角、凹の角ではその辺のオフセットの終点になる。これにより、縫い線は隣接する辺からも `offset` だけ離れて終わる（単純な平行移動だと端が外形に接してしまう）。

## 許容誤差

| 量 | 許容 | 根拠 |
|---|---|---|
| 曲線の平坦化 | 0.02 mm（TypeFab 共通） | 弧長誤差は曲線長の 10⁻⁴ 程度 |
| 穴輪郭の平坦化 | 0.005 mm | 直径 0.3〜1.5 mm の穴でも実寸ずれ < 0.01 mm |
| Clipper オフセット | 1e-4 mm（SCALE 10000） | 整数座標化 |
| 弦長ピッチの一様性（テスト） | 区間内 max−min < 0.02 mm | `tests/stitch.test.js` |
| 設計寸法と SVG の一致（テスト） | 0.01 mm | `tests/svg-verify.test.js`（独立パーサで再読込） |
| 開いた辺のオフセット端点 | 0.01 mm | 平坦化面の法線誤差 |

## 検証したケース（`tests/stitch.test.js`）

直線（arc/fixed/count/余白）、円（弧長と弦長の差、r=3 の急カーブ）、閉曲線の開始位置・逆方向、正方形（apex/straddle/none・対称性）、auto の選択規則、角丸長方形（ベジェ）、凹の L 字、30° の鋭角、穴形状の寸法と向き、ミラー、正規化、決定論。

## 曲線を含む角のフィレット（`src/leather/fillet.js`）

`cad.js` の `filletCorner` は、角の両側が直線なら従来の解析解、どちらかが曲線なら `filletCurvedCorner` を使う。両側の区間を 256 分割でサンプルし、角からの弧長 dA, dB の点で曲線に接する半径 r の円の中心が一致するよう、黄金分割探索を入れ子にして解く（中心のずれ > 0.02 mm なら「収まらない」エラー）。接点で `insertNode`（形状を変えないド・カステリョ分割）して角ノードを削除し、A→B を接線方向のハンドル（k = 4/3·tan(φ/4)·r）の 3 次ベジェ円弧で置き換える。テスト: 直線どうしで解析解と一致、直線×曲線（90°）、曲線×曲線のカスプ（r = 3, 8 で円弧半径誤差 < 0.05 mm、対称）、閉パスのノード 0。
