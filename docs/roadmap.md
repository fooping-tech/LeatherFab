# 既知の制約とロードマップ

## 実装済み（Phase 1 完了）

- TypeFab ベースの独立アプリ（静的サイト、アカウント不要、ローカル保存）
- 基本図形編集（TypeFab 継承: 矩形・楕円・多角形・線・フリーハンド・パス編集・ブール・オフセット・フィレット・ミラー・パターン・寸法）
- LeatherPart（革厚・材料・枚数・表裏・加工属性）、`schemaVersion`
- 自動縫い線（全周／辺を選んで追加・隣の辺で延長）、自動縫い穴（5 形状、弧長/弦長、自動/固定/穴数、角 apex/straddle/auto、開始位置、余白、逆目打ち、ミラー）
- 外形変更への追従（移動・拡縮・回転・ノード編集・ブール後の再マップ）
- 縫合（StitchJoint）: 穴数一致、正規化座標の位置ずれ・長さ差の表示 ※Phase 2 項目を前倒し
- 折り線（辺に平行、SCORE）、金具 17 プリセット＋ユーザー定義、材料のレーザー適性表示
- 加工前検証（未閉合・自己交差・重複カット・微小パス・はみ出し・穴の縁距離・穴の干渉・無効参照・縫合の不一致）
- カーフ補正付き SVG（CUT/PUNCH/SCORE/ENGRAVE グループ、mm 実寸）、JSON 保存
- テンプレート: AirTag ケース、カードケース（編集可能な LeatherPart）
- ミラーコピー（穴の傾き反転・自動縫合・元→コピーの一方向リンク）、合体／抜く、金具のドラッグ（中心線・他金具・1 mm グリッドにスナップ）、曲線を含む角のフィレット
- 操作履歴（タイムライン）: 基本形状の寸法、フィレット／面取り／丸穴／長穴をパラメトリックに再生成。履歴外の編集は検出して選択を促す
- 重ねたパーツへの穴の投影（上のパーツの縫い線を下のパーツに自動で写す。相対位置を記憶、ピッチ変更に追従）
- 穴の個別削除／復元（正規化位置で記録、縫合相手の対応穴も省く）

## 既知の制約

- DXF・1:1 PDF・A4 分割印刷は未実装（Phase 2）。
- 縫い線の参照は「ノード番号」。パス編集でノードを追加・削除すると番号がずれ、辺の範囲が意図と変わる、または無効になる（警告は出す）。LeatherCAD のように「どの入力コーナーがどこへ行ったか」を追跡する写像は未実装。
- 折り線は辺に平行な線のみ。任意位置の折り線・接着領域・縫い代の自動生成は未対応。
- `side: back` は属性のみで、書き出し時の自動ミラーは未実装。ミラーコピーは形状を実際に反転した独立パーツとして作る。
- ミラーコピーは元に一方向でリンクされる。コピー側の編集は、次に元が変わったときに元の内容で上書きされる（コピー側の変更を残したい場合は「リンクを解除」）。ミラー側だけを編集した状態では形状の対称性は保たれず、縫合が穴数を合わせ長さ差を警告する。
- 革厚を使った寸法補正（折り返しの内外周差）は未実装。
- 縫合は 2 本の縫い線の 1:1 対応のみ。穴の途中からの対応、複数パーツの連鎖は未対応。
- 金具の寸法は目安。
- 材料ネスティング、3D、STL 治具は未実装。
- 実機加工は未検証。

- 操作履歴に記録されるのはフィレット・面取り・丸穴・長穴と基本形状の寸法のみ。ブール演算・オフセット・パス編集・拡縮は記録されず、行うと履歴が「外部で編集」状態になる。
- 履歴の角参照はノード番号（その操作時点のパス）。操作を削除すると後続の番号がずれる。

## Phase 2（革製品設計機能の充実）

- DXF（R12 POLYLINE、加工属性ごとのレイヤー）、1:1 PDF（校正マーク、A4/Letter タイル、重なり・トンボ）
- 参照画像のトレース＋2 点校正
- ノード追跡付きの辺参照（コーナー写像）
- 任意折り線・接着領域・縫い代オフセットの派生
- 裏パーツの自動ミラー書き出し、縫合の部分対応
- 金具プリセットの UI 編集、縫い線の複列・千鳥

## Phase 3（差別化）

- 寸法入力による型紙自動生成（カードケース・キーケース・コインケース）
- 複数パーツの連動設計（共有縫い線をワールド座標オブジェクトとして持つ）
- 材料ネスティング、加工コスト見積もり
- 3D 組み立てプレビュー、革厚と折り構造の補正、STL 治具

Phase 3 は `src/leather/` に新モジュールを足す形で実装でき、Phase 1 の構造を変えない。
