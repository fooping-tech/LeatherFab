# 競合調査: Tannera / LeatherDraft（2026-10-24 調査）

凡例: ✅確認済み / △部分対応・記述あいまい / ❓未確認（記載なし。非対応とは限らない）

## D. Tannera（figbell）

テンプレート選択＋寸法入力で部品と縫い穴を自動計算する「レザー型紙メーカー」。自由曲線は描けず、矩形＋角R に限定したパラメトリック専用ツール。日本語ページあり（https://www.figbell.com/ja/tannera）。

- ✅ Web版（PWA、オフライン可、タッチ対応）: app.figbell.com/tannera/ — https://www.figbell.com/en/tannera/features
- △ デスクトップ・iOS/Android は「Coming soon」表記 — /en/tannera/download
- ✅ 価格 $7.99 買い切り — /en/tannera/info

| 項目 | 判定 | 内容 |
|---|---|---|
| 寸法入力からの型紙生成 | ✅ | カードケース(1〜4ポケット)、二つ折り/長財布、パスポートケース、キーフォブ、ペンケース、時計ベルト、ベルト。カード/紙幣/パスポート等のサイズプリセット |
| 部品間の縫い穴共有 | ✅ | 「上に重なる部品は下の部品から穴を継承」「接合辺は同じ穴数」。穴は角から開始し等間隔に丸め |
| 革厚・縫い代 | △ | 入力パラメータとして存在。計算への反映方法は非公開 |
| マルチポケット | ✅ | ポケット数と段差をテンプレごとに設定 |
| テンプレート構造 | △ | 自動計算後にドラッグ/数値でリサイズ可。ノッチ・スロット・スナップ・リベット・折り線・目方向・数量・鏡像裁断を編集可 |
| 1:1印刷 | ✅ | 100%印刷、10mm/1inch校正正方形、A4/Letterタイル分割、トンボ、ページマップ |
| ローカル保存 | ✅ | IndexedDB、サーバ送信なし、.tannera（JSON） |
| エクスポート | ✅ | PDF、SVG（切断=赤、折り=青）、DXF。インポート不可 |
| 縫い穴ピッチ | ✅ | 菱目間隔 2.7〜4 mm、穴径指定可 |
| 糸長見積 | ✅ | 縫い長×4＋30 cm |

参考: 穴整合モデル（下の部品の穴を継承、接合辺の穴数一致）、寸法プリセット＋ポケット数の最小パラメータ設計、PDFタイル印刷の仕様、完全ローカル。
弱点: 自由曲線不可、インポート不可、Web以外は未実体、革厚ロジック非公開。

## F. LeatherDraft

財布・カードケース向けオフライン2Dレザー型紙CAD。クローズドベータで一般配布なし（https://www.leatherdraft.com/ , /guide）。

- ✅ Windowsポータブル版、macOSネイティブ版。ネットワーク非接続、.ldraft（JSON）
- ❓ Web版、iPad、価格・ライセンス

| 項目 | 判定 | 内容 |
|---|---|---|
| 実寸設計 | ✅ | mmキャンバス、ベジェ輪郭（corner/smooth/rounded/chamfer ノード）、数値指定 |
| 金具ライブラリ | ✅ | スナップ、マグネット、ハトメ、シカゴスクリュー、リベット、カードスロット、丸穴。穴径＋外径、品番、部品へのアタッチ、辺からの距離 — /guide/hardware |
| 縫い目計算 | ✅ | 縁マージン＋間隔、SPIプリセット→mm上書き、穴数⇄間隔の双方向再計算、穴数・実間隔・余りの表示、中央対称配置、始終点オフセット、閉曲線の開始点指定、曲線上で菱目が入らない場合の警告、丸/ダイヤ穴 — /guide/stitch |
| 部品間の穴同期 | △ | 「Link to parent stitch」（記事未執筆） |
| SVG/PDF/STL | ✅ | SVG実寸、PDF 1:1（5 mm重なりタイル）、STL治具 |
| 印刷校正 | ✅ | 50×50 mm校正マーク |
| 3Dプレビュー / ネスティング / モバイル | ❓ | 記載なし |
| 補助 | ✅ | オフセット、ミラー、寸法線、Belt Maker、Pre-cut監査（自己交差・極小R・未アタッチ金具） |

参考: 縫い線UIの要件（SPIプリセット、穴数⇄間隔、余りの可視化、始終点オフセット、閉曲線の開始点）、金具の「部品にアタッチ＋辺からの距離」、Pre-cut監査。
弱点: 入手不可、パラメトリックはベルトのみ、穴同期は未文書化。
