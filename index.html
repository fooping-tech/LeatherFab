革の型紙を、
すぐに。

図形を描いて「縫い穴を作る」を押すだけで革パーツに。外形を変えても縫い穴が追従し、レーザー加工用の実寸 SVG をそのまま書き出せます。インストール不要、アカウント不要、データはブラウザの中だけ。

無料で使ってみる →PC / iPad / スマートフォンのブラウザ対応
✦

描いてすぐ作れる

長方形・楕円・多角形・フリーハンド・ベジェパスで外形を描き、ワンクリックで縫い線と縫い穴。辺をクリックして部分的な縫い線も引けます。

⟲

編集しても壊れない

縫い穴は座標ではなくパラメータとして保持。移動・拡縮・回転・ノード編集・ブール演算に追従し、参照が無効になれば警告します。

⊕

弧長と弦長を区別

目打ちの刃がまたぐ直線距離（弦長）で配置できるので、曲線でも実際の工具と一致。穴数・実ピッチ・SPI を常に表示します。

⟗

パーツ間の穴合わせ

2 つのパーツの縫い線を「縫合」すると穴数を一致させ、位置ずれと長さ差を表示。表裏・本体とポケットがきれいに縫い合わさります。

◎

金具・折り線・革厚

バネホック、カシメ、ハトメ、マグネット、Dカン、ベルト穴のプリセット。折り線は SCORE、革厚と材料はパーツごとに管理します。

↗

製作まで最短距離

CUT / PUNCH / SCORE / ENGRAVE をグループ分けした mm 実寸 SVG。カーフ補正と加工前チェック（自己交差・重複・穴の縁距離・材料適性）付き。

使い方は 4 ステップ

  1. 図形を描く長方形や楕円を置いて、フィレットやパス編集で形を整えます（mm 実寸）。
  2. 縫い穴を作る図形を選んでボタンを押すと革パーツになり、外周 3 mm 内側に穴が並びます。
  3. 調整するピッチ（3.0 / 3.38 / 3.85 / 4.0 mm…）、穴の形（丸・菱目・フレンチ・スリット・平目）、角の処理をリアルタイムに。
  4. 書き出す加工プレビューで確認して SVG をダウンロード。レーザーカッターや目打ちガイドの印刷に。

加工データを、曖昧にしない

  • 加工属性は線色ではなくデータとして明示（data-operation 付きグループ）
  • 切断順に並ぶ ENGRAVE → SCORE → PUNCH → CUT
  • カーフ補正: 外形は外へ、穴は内へ、半分ずつ
  • 書き出し前の検証: 未閉合・自己交差・重複カット・微小パス・はみ出し・穴と縁の距離・穴どうしの干渉・縫合の不一致
  • 材料のレーザー適性を表示。不明な革を「加工可」とは言いません

テンプレートから始める

  • AirTag ケース — 表（Ø24 の窓）と裏（キーリング穴）。上辺以外を 3.85 mm ピッチの菱目で縫合済み
  • カードケース — 本体とポケットの 3 辺を縫合、穴数とピッチが一致
  • どちらも通常の革パーツなので、サイズ・角の丸み・ピッチを自由に変えられます

iPad・スマートフォンでは下部バーからオブジェクト・ツール・編集のシートを開き、ピンチでズーム、2 本指でパンします。

仕様

対応ブラウザ最新の Chrome / Edge / Safari / Firefox（PC、iPad、スマートフォン）。インストール・アカウント不要
入力図形ツール、SVG / DXF の読み込み、PNG / JPEG / GIF の輪郭トレース、プロジェクト JSON
縫い穴丸・菱目・フレンチ・斜めスリット・平目。弧長 / 弦長ピッチ、自動フィット / 固定 / 穴数、角は apex / straddle / 自動、開始位置、余白、逆目打ち、ミラー
出力SVG（mm 実寸、CUT / PUNCH / SCORE / ENGRAVE グループ、カーフ補正）、プロジェクト JSON。DXF・1:1 PDF は今後対応
データブラウザ内で処理・自動保存。外部送信なし
注意穴径・ピッチ・カーフは材料と加工機でテスト加工して決めてください。チェックは加工結果を保証しません
